1. 아이디어 고르기

10:48 · 5분

끝나면: 만들 게임을 한 문장으로 말할 수 있다.

이미 만들고 싶은 게 있으면 건너뛰세요. 없으면 AI에게 물어봅니다. 노란 부분은 여러분의 관심사로 바꾸세요.

AI에게 보낼 말
나는 게임 기획을 처음 해 보는 대학생이야. [좋아하는 것: 예) 여수, 고양이, 축구, 시험기간]을 소재로 한 아주 단순한 웹 미니게임 아이디어를 5개 제안해 줘.
조건: 한 손으로 1분 안에 한 판이 끝나고, 규칙을 한 문장으로 설명할 수 있어야 해.
각 아이디어마다 "플레이어가 반복하는 행동"과 "재미 포인트"를 한 줄씩 써 줘.

고르는 기준은 하나입니다. 작을수록 좋다. RPG나 오픈월드가 떠오르면 그 게임의 10초짜리 한 장면만 떼어 오세요.

위 기획서를 채우면 아래 글이 자동으로 완성됩니다. 통째로 복사해서 AI에게 보내세요. Gemini는 Canvas를 먼저 켭니다.

4. 바꿔서 플레이하고 개선하기
11:23 · 20분

    
끝나면: 남의 피드백으로 게임을 두 번 이상 고쳤다.

    
    
      
  1. 4분 옆 조와 자리를 바꿔 서로의 게임을 합니다. 설명하지 말고 지켜보세요. 어디서 헤매는지가 가장 값진 정보입니다.
    2. 
      
  2. 2분 세 가지를 물어봅니다. 뭐가 헷갈렸나요? 언제 지루했나요? 뭐가 있으면 한 판 더 하고 싶을까요?
    3. 
      
  3. 14분 가장 중요한 것부터 고칩니다. 한 번에 한 가지만 요청하세요. 여러 개를 한꺼번에 시키면 어디서 망가졌는지 알 수 없습니다.
    4. 
    

    
개선 요청 메뉴

    

      

        
너무 쉽거나 너무 어려울 때

        
난이도

        
처음 20초는 지금보다 쉽게, 그 뒤로는 시간이 지날수록 점점 어려워지게 난이도 곡선을 조정해 줘. 1분쯤 버티면 꽤 어렵다고 느껴지는 정도로.

      

      

        
밋밋하고 손맛이 없을 때

        
손맛

        
손맛을 살려 줘. 점수를 얻으면 반짝이는 파티클과 "+10" 숫자가 뜨고, 피해를 입으면 화면이 짧게 흔들리게 해 줘. 효과음도 소리 파일 없이 코드로 만들어서 넣어 줘.

      

      

        
한 판 더 하고 싶은 이유가 없을 때

        
새 요소

        
가끔 등장하는 특별한 요소를 하나 추가해 줘: [예) 5초간 무적이 되는 아이템 / 점수 5배짜리 희귀한 것 / 10초마다 나오는 보스]. 등장할 때 눈에 띄게 표시해 줘.

      

      

        
처음 하는 사람이 규칙을 몰라 헤맬 때

        
안내

        
처음 하는 사람이 설명 없이도 알 수 있게, 시작 화면에 조작법과 규칙을 그림 위주로 세 줄 이내로 보여 줘.

집에서: GitHub에 올려 내 주소 만들기
10분

    
끝나면: https://아이디.github.io/my-game/ 에서 내 게임이 열린다.

    
GitHub는 전 세계 개발자가 코드를 올려 두는 곳입니다. 여기서 GitHub Pages를 켜면 올린 HTML 파일이 그대로 웹사이트가 됩니다. 공개 저장소라면 무료이고, AI 대화가 사라져도 주소는 남습니다. 만든 게임이 쌓이면 그대로 포트폴리오가 됩니다.

    
    
      
  1. 위에서 저장한 게임 파일의 이름을 index.html로 바꿉니다.
    2. 
      
  2. github.com에 가입하고, 오른쪽 위 + → New repository를 누릅니다. 이름은 my-game, 공개 범위는 Public으로 하고 만듭니다.
    3. 
      
  3. 저장소 화면에서 Add file → Upload files를 누르고 index.html을 끌어다 놓은 뒤 Commit changes를 누릅니다.
    4. 
      
  4. Settings → 왼쪽 메뉴 Pages → Source를 Deploy from a branch로, Branch를 main으로 고르고 Save를 누릅니다.
    5. 
      
  5. 몇 분(최대 10분) 기다리면 Pages 화면 위쪽에 주소가 뜹니다. 그 주소를 친구에게 보내세요.
    6. 
    

    
게임을 고친 뒤에는 새 index.html을 같은 방법으로 다시 올리면 덮어써집니다. 화면이 설명과 다르면 AI에게 물어보세요.

    

      
막혔을 때 AI에게

      
GitHub Pages에 index.html 파일 하나로 된 게임을 올리고 싶어. 코딩을 모르는 사람 기준으로, 지금 GitHub 화면에서 어디를 눌러야 하는지 순서대로 알려 줘. 나는 지금 [막힌 단계와 보이는 화면]에 있어.

    

  


  

    
막혔을 때

    

      

        
상황해 볼 것

        
          
게임이 안 뜬다버그 신고 틀로 한 번 요청. 두 번 실패하면 새 대화를 열고 3단계 요청문을 다시 보냅니다.

          
고쳤더니 더 망가졌다"방금 수정을 취소하고 그 전 버전으로 돌려 줘"라고 말합니다.

          
사용 한도 메시지조원의 계정이나 다른 AI로 옮기고 3단계 요청문부터 이어 갑니다.

          
AI가 코드만 보여 준다"바로 실행해서 볼 수 있게 미리보기로 보여 줘"라고 요청하거나 파일로 저장합니다.

          
일찍 끝났다두 번째 적, 스테이지, 엔딩 화면, 배경 음악 중 하나에 도전하세요.
