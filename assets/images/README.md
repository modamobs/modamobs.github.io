# 이미지 폴더

프로젝트 스크린샷을 여기에 넣으세요.

## 사용법

1. 이미지를 이 폴더에 저장합니다. 예: `undead.png`
2. `js/projects.js`에서 해당 프로젝트의 `thumb` 값을 채웁니다.

```js
{
  title: "Undead",
  thumb: "assets/images/undead.png",
  ...
}
```

`thumb`가 비어 있으면 제목 첫 글자로 만든 대체 썸네일이 표시됩니다.

## 권장 사양

- 비율: 16:10 (카드가 이 비율로 잘라냅니다)
- 크기: 가로 800~1200px
- 형식: WebP 또는 PNG/JPG
