게임 올리기

직접 만든 웹 게임을 zip으로 올리면 피드의 신규 탭에 바로 뜹니다.

게임을 올리려면 구글 계정으로 로그인해 주세요.

로그인하면 이용약관과 개인정보 처리방침에 동의하는 것으로 봅니다. 만 14세 미만은 게임을 올릴 수 없어요. 올린 게임에는 구글 계정 이름이 함께 공개됩니다.

이렇게 만들어 주세요

처음이라면 샘플 게임(별 잡기) zip을 받아 고쳐 보세요. 점수 보내기까지 들어 있습니다.

  • 세로 화면(폰 비율)으로 만들면 피드에서 꽉 차게 보입니다.
  • 필요한 파일은 모두 zip 안에 넣어 주세요. 라이브러리는 jsDelivr·cdnjs·unpkg에서 불러올 수 있습니다.
  • 보안 때문에 바깥 서버로의 통신(fetch, 외부 이미지 등)은 막혀 있습니다. 저장은 localStorage를 쓰세요.
  • 한 판이 끝날 때 점수를 보내면 피드에 내 최고 기록이 남습니다. 
    parent.postMessage({ type: "mobs:score", score: 1234 }, "*");
parent.postMessage({ type: "mobs:end" }, "*");  // 한 판 끝
  • Unity WebGL은 압축 없음(Disabled)으로 빌드해 주세요.
