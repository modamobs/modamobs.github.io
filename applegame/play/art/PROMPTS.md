# ChatGPT 이미지 프롬프트 (펠트)

게임에 쓰는 그림은 ChatGPT로 만들었어요. 다시 만들 때는 아래 프롬프트를 하나씩 넣고,
나온 이미지를 **이 폴더(`www/art/`)에 표의 파일 이름 그대로** 저장해 주세요.
파일이 없으면 CSS로 그린 사과와 펠트가 대신 나와요.

| 파일 이름 | 크기(저장할 때) | 배경 |
|---|---|---|
| `felt-apple-1.png` | 256×256 | 투명 |
| `felt-apple-2.png` | 256×256 | 투명 |
| `felt-apple-3.png` | 256×256 | 투명 |
| `felt-bg.jpg` | 768×768 | 채움 |
| `felt-board.jpg` | 768×768 | 채움 |

사과 세 장은 **같은 대화창에서 이어서** 만들어야 바느질과 그림체가 맞아요.
사과 가운데에는 숫자 패치가 붙으니 무늬 없이 비워 둬요.
